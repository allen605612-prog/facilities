## 三、建議人工補充的資料

### 優先補充（核心規則文件）

1. **Google Docs 規則文件（8 份）**  
   → 請用 Google 帳號開啟各文件，另存為 PDF 或 Word，放入 `設備組網頁/` 目錄。  
   → 建議存為：`教學設備管理規則_01.pdf`、`專科教室管理規則_01.pdf`… 等。

2. **活動一覽表試算表**  
   → 請登入 Google 帳號後開啟，選「下載 → Excel/CSV」，或截圖儲存。  
   → 或可直接在 `活動一覽表.html` 中補上靜態文字版本。

### 次要補充（提升完整性）

3. **設備報修系統說明截圖**  
   → 進入 Google Sites 後，截圖儲存「如何填寫報修單」說明，存為 `設備報修說明.png`。

4. **數學與自然科能力競賽報名資訊**  
   → Google Form 被限制，建議補充：報名截止日期、競賽科目、參賽資格等文字說明。

5. **校徽高解析版本**  
   → `jhs-logo.png` 目前僅 10.5 KB（寬度約 96px），若新網站需要較大版本，請向學校索取 SVG 或高解析 PNG。

6. **學校官網公告原文（2 則）**  
   → 科展得獎公告原文（國中小科展、高中分區科展），目前只有外部連結。若需保留本地備份，請手動複製貼上頁面內容。
