# 設備組工具

## 產生得獎匯入總表

把整理好的競賽得獎名單轉成校務系統的 16 欄匯入格式。

- `產生得獎匯入總表.py` — 主程式
- `產生得獎匯入總表.ps1` — 雙擊執行用的包裝（UTF-8 with BOM）

實際使用的工作副本放在 `D:\D\114設備組\`，這裡是版控備份，改動後記得兩邊同步。

### 用法

```powershell
uvx --with openpyxl python 產生得獎匯入總表.py
uvx --with openpyxl python 產生得獎匯入總表.py 輸入.xlsx 輸出.xlsx
```

不帶參數時，預設 `D:\D\114設備組\國中科展得獎名單_整理.xlsx` → `D:\D\114設備組\65屆縣科展得獎名單總表.xlsx`。

### 輸入檔欄位

第一列為標題，以名稱對應、順序不拘：

> 屆別　科別　名次　題目　班級　學號　座號　姓名　指導老師　備註　比賽日期　證書日期　證書文號

### 轉換規則

| 輸出欄位 | 來源 |
|---|---|
| 學年／學期 | 由比賽日期推算（民國年 −1，學期固定 2） |
| 競賽項目 | `雲林縣第N屆公私立國中小科學展覽競賽榮獲國中組{科別}{名次}` |
| 競賽時間／證書日期／證書字號 | 取自輸入檔 |
| 班級 | 「2年美甲班」→ `810`（(年級+6)×100 + 班序） |
| 名次 | 「第三名」→ `3`；說明欄保留原文字 |
| 性質／類別／組別／提報人／主辦單位 | 固定值：全縣／資訊類／個人賽／A130／雲林縣政府 |

班序預設 `正 心 誠 意 修 身 齊 音甲 音乙 美甲 美乙`。某些年級若無「齊」班，序號會往前遞補，在腳本上方的 `班序覆寫` 依年級設定。

### 注意事項

- 舊的輸出檔會自動備份成 `..._備份_YYYYmmdd_HHMMSS.xlsx`。
- 輸出檔若正被 Excel 開啟會先擋下並提示，不會做到一半才失敗。
- 班級解析失敗、日期非 7 碼民國格式、屆別與年份對不上、缺學號，都會在執行結束時列出警告。
- 證書字號同一屆共用一個發文字號（一份公文對應全部得獎人），不是每人一個連號。
